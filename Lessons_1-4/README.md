# Room 34 Poets Society — Week 1 Lessons 1–4 correction pack

Four lesson folders contain teacher-only master documents, student-facing text (no answers), and structured JSON for later website integration. **Do not distribute the teacher files to students.** Student documents contain all five group readings: show only the selected group in the eventual student interface. Group reading levels are not exposed in student content.

Each group has one original reading in the agreed word-count range, ten defined vocabulary terms, four timed spelling/vocabulary activities, passage-specific MCQs, written questions with exemplar responses, a writing task and reflection. Each lesson contains 57 questions across groups; four lessons contain 228 questions.

**Important validation limits:** Automated checks verify word counts, question counts, unique options, answer indices, vocabulary counts and time allocations. The question bank and text have been drafted and reviewed for alignment, but this is **not** an independently standardised NZ reading-level assessment or a classroom trial. The MCQ hint text is contextual rather than fully handcrafted. Lessons 1–4 are reconstructed from the earlier conversation's lesson themes and character scenarios; they are not verbatim copies of any inaccessible prior full drafts.

Use the Lesson 5 corrected pack separately. Do not use the old structural 200-experience draft as classroom content.
