# Lesson 5 — QC correction pack

This package supersedes the **structural draft** for Week 1 Lesson 5 only. It does not certify the other 39 lessons.

- `lesson5_teacher_master.md`: full reading, spelling activities, question keys, exemplars and hints. Teacher-only.
- `lesson5_student_all_groups.md`: student-facing readings and tasks without keys or hints. Present only the selected group to each student.
- `lesson5_validated.json`: structured data for later website integration. Group levels are intentionally absent from student-visible fields.
- `lesson5_validation.csv`: measured word counts and question coverage.

Validation is mechanical for length, count, and answer structure, plus editorial alignment. No independent NZ readability standardisation or classroom trial has been performed. Reading-level targets remain approximate.
